# Politique de sécurité

Ce dépôt héberge le cyberfolio de Damien Dathueyt, publié sur https://zyphang.github.io/.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique**. Utilise plutôt le signalement privé de GitHub :
**Security → Report a vulnerability** (https://github.com/Zyphang/Zyphang.github.io/security/advisories/new),
ou contacte-moi via LinkedIn.

Je m'engage à accuser réception sous 7 jours et à te tenir informé de la correction.
Les tests doivent rester non destructifs et ne pas cibler l'infrastructure de GitHub
(elle a son propre programme : https://bounty.github.com).

## Périmètre

Site 100 % statique (HTML/CSS/JS), sans back-end, sans cookie, sans formulaire et sans ressource tierce.
Voir la section « Sécurité » du README pour le détail des protections et de leurs limites.
